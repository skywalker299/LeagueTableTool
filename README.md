# League Table Tool

A Python-based football league(Premier League) table application using:

-Python
-SQlite
-Flask
-HTML/CSS
-Object-oriented programming

## Features

-Create teams
-Create fixtures
-Record match results
-Calculate league standings
-Console interface
-Web inteface

## Running the program
git clone https://github.com/skywalker299/LeagueTableTool.git
cd LeagueTableTool
Console version: python main.py console
Web version: python main.py web (Prefered)
Launching the main.py from the GUI or without input in the console 
will automatically start the web version

The SQLite database is created automatically at first launch
